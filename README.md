# AEP
Repositório criado para armazenar a documentação dos códigos presentes no sistema que serão desenvolvidos no 2º Semestre

#PSE em Ação

Sistema desenvolvido em linguagem C para auxiliar no planejamento e acompanhamento de ações de atividade física nas escolas participantes do Programa Saúde na Escola (PSE).

#Objetivo:

Organizar as informações das atividades realizadas nas escolas, facilitando o cadastro, a consulta e o acompanhamento das ações e da participação dos estudantes.

#Funcionalidades:

Cadastro de ações do PSE;
Pesquisa por escola, tema ou código;
Listagem das ações cadastradas;
Atualização do status: planejada, realizada ou cancelada;
Registro da quantidade de participantes;
Resumo geral das ações.

#Tecnologias:

Linguagem C
Terminal / Linha de comando
Git e GitHub

#Sobre:

O projeto busca aplicar conhecimentos de programação e lógica na criação de uma solução simples para melhorar a organização das ações de atividade física desenvolvidas no ambiente escolar.
